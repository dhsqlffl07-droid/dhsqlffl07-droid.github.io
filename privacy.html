개인정보처리방침

시행일: 2026년 11월 2일

온골쇄신(이하 "회사")은 사내 전용 프로그램 "온골쇄신 통합웹"(이하 "프로그램")을 운영하며, 프로그램이 다루는 정보를 아래와 같이 처리합니다.

1. 프로그램을 쓰는 사람

프로그램은 회사 대표와 직원만 사용합니다. 회원 가입 기능이 없고, 관리자가 만든 회사 계정으로만 로그인합니다. 일반 고객의 정보는 프로그램에 입력하지 않습니다.

2. 구글 사용자 데이터에 접근하는 방법

  • 프로그램은 회사 업무용 구글 계정 한 개의 구글 드라이브에 OAuth 방식으로 연결합니다(권한 범위: Google Drive).
  • 프로그램이 만든 "온골쇄신 통합웹" 폴더 안의 파일과 폴더만 만들고, 올리고, 이름을 바꾸고, 옮기고, 폴더 공유 권한을 주거나 해제합니다.
  • 그 폴더 밖의 파일 내용은 읽거나 바꾸거나 지우지 않습니다. 파일을 영구 삭제하는 기능은 없습니다.

3. 저장하는 정보와 쓰는 목적

  • 드라이브 파일의 이름, 위치(폴더), 크기, 파일 식별값(ID·체크섬), 올린 시각과 올린 직원 이름 — 상품별 업무 파일을 찾고 정리하기 위해 회사의 업무 데이터베이스(Supabase)에 저장합니다.
  • 드라이브 연결 토큰 — 회사 PC의 설정 파일에만 보관하며 화면이나 다른 곳에 보여 주지 않습니다.
  • 이 정보는 회사 내부 업무에만 쓰며, 광고·판매·제3자 제공에 쓰지 않습니다.

4. 구글 API 서비스 사용자 데이터 정책 준수

프로그램이 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

The use and transfer of information received from Google APIs by this app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. 보관과 삭제

파일 정보는 회사가 업무에 쓰는 동안 보관합니다. 드라이브 연결을 끊으려면 구글 계정 설정의 "보안 › 타사 앱 액세스"에서 "온골쇄신 통합웹" 접근을 해제하면 됩니다. 해제하면 프로그램은 더 이상 드라이브에 접근하지 못합니다.
